ANG Cric Dose website prototype

Files:
- index.html: audience page, scorecard tabs, login/sign-up interface
- admin.html: operator/admin console
- assets/ang-cricdose-logo.png: logo asset
- firebase-config.js: Firebase web config placeholder (must be configured before login works)
- SETUP_AUTH.txt: setup and security instructions for email + phone authentication and reading history

Open on a local web server for basic UI preview. Firebase phone login requires an authorized HTTPS domain and Firebase setup. The prototype does not become a hosted website automatically; upload all files together to your hosting provider. Existing localStorage data is not automatically migrated to Firestore.
